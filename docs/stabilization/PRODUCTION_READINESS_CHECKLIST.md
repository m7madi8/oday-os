# قائمة جاهزية الإنتاج — بعد المرحلة 7C

المرحلة 7C لم تُعد تشغيل الاختبارات. REL-B2 لاحقاً شغّل النسخة المغلفة على قاعدة معزولة. سطح المكتب 1.0 والجوال 1.0 كلاهما `NO-GO`.

هذه القائمة لا تمنح إذن نشر. كل بند بلا دليل يبقى خارج `VERIFIED`.

| البند | الحالة | الدليل والحد |
|---|---|---|
| اتصال قاعدة الإنتاج | NOT VERIFIED | لم تُستخدم قاعدة `ninja` على 3306. التحقق كان على `oday_financial_verification` في `127.0.0.1:3307`. |
| HTTPS | NOT VERIFIED | محليًا: HTTP يُرفض، ووكيل موثوق يُقبل، و`X-Forwarded-Proto` من عنوان غير موثوق يُرفض. لا وكيل إنتاج حي. |
| إعداد API العام | NOT VERIFIED | لا عنوان إنتاج موثّق في المستودع. |
| المصادقة | VERIFIED | رمز غير الصالح مرفوض. مسار items القديم يعيد 410 مع الرمز الثابت. اختبارات الجلسة في الواجهة 5/5 والجوال 2/2. |

| الأسرار | NOT VERIFIED | لم تُطبع القيم ولم تُدوَّر أسرار إنتاج. المثال يبقي المفاتيح فارغة. مستودع الأسرار التشغيلي غير مُراجع على الخادم. |
