# تحديثات تطبيق ODAY OS لسطح المكتب

ضع هنا مخرجات `npm run desktop:build` من مجلد `dashboard`:

- `latest.yml`
- `ODAY-OS-Setup.exe`
- ملف `.blockmap` إن وُجد
- `version.json` (يُكتب تلقائيًا)

التطبيق المثبت يتحقق من `{عنوان الخادم}/desktop-updates` ومن `/api/oday/desktop/version`.
عند وجود إصدار أحدث يُنزَّل ويُثبَّت فورًا مع إشعار.

**مزامنة واجهة الويب بدون مثبّت جديد:** إذا كان عنوان الخادم محفوظًا (مثل `http://192.168.x.x:8000`) ولوحة الويب تعمل على نفس الجهاز (`npm run dev` على المنفذ **5173**)، يحمّل تطبيق Windows الواجهة من الويب مباشرة — أي تحديث على المتصفح يظهر في سطح المكتب بعد إعادة فتح التطبيق أو حفظ عنوان الخادم من الإعدادات.

لنشر مثبّت جديد بعد تغييرات كبيرة في التطبيق نفسه:

```bash
cd dashboard
npm run desktop:build
```
